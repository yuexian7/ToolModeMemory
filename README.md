# Tool Mode Memory

记住工具面板设置，并按存档持久化。默认关闭 = 完全原版行为。

## 功能

- 每个存档一份记忆（`ModsData\ToolModeMemory\<存档名>.json`）
- 退出覆盖写入，下次进入自动恢复
- 「设置共用范围」：同组 / 同菜单 / 同类资产 / 全局共用 / 全局不共用
- 「记忆管理」：重置记忆、打开记忆文件夹
- 12 种官方语言
- 零 Harmony，不修改游戏文件

## 本地构建

```powershell
dotnet build -c Release
```

部署到游戏 Mods 目录由官方工具链 `DeployWIP` 完成。  
**本版本不上传 Paradox Mods。**

## 设置摘要

| 标签页 | 内容 |
|---|---|
| 模组设置 | 总开关（默认关）+ 14 个工具项 × (启用, 范围) |
| 记忆管理 | 重置记忆 / 打开记忆文件夹 |
